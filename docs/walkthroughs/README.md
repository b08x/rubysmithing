# Walkthroughs

Step-by-step examples of common rubysmithing workflows.

| Walkthrough | What You'll Build |
|:------------|:-----------------|
| [New Project](new-project.md) | Scaffold a Ruby app or gem from scratch |
| [Analyse a Codebase](analyse-codebase.md) | Audit an existing codebase using Gemba Walk, Muda, or Root-Cause Tracing |
| [Generate a Task Backlog](generate-backlog.md) | Turn analysis findings into an actionable development backlog |
| [Text Processing Gem](text-processing-gem.md) | Build a publishable gem for text normalization and tokenization |

Each walkthrough is self-contained. Start with whichever matches your current task.
